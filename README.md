# Сайт юриста под рекламу (Яндекс Директ, Авито и др.)

Одностраничный лендинг без сборки: HTML + CSS + JS и обработчик заявок `send.php`.
Работает на любом хостинге с PHP 7.4+ (Beget, Timeweb, REG.RU и т. п.).

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Лендинг: первый экран с оффером, услуги, этапы работы, обо мне + цифры, квиз, отзывы, форма, FAQ, контакты |
| `thanks.html` | Страница «Спасибо» после заявки (на неё ставится цель в Метрике) |
| `privacy.html` | Политика обработки персональных данных (152-ФЗ) — шаблон |
| `assets/js/config.js` | **Настройки**: номер Метрики, тексты офферов под объявления |
| `assets/js/main.js` | UTM-метки, цели Метрики, формы, маска телефона, квиз, модалка |
| `send.php` | Отправка заявок в Telegram и на почту + резервный журнал `leads.log` |
| `config.sample.php` | Пример настроек отправки → скопировать в `config.php` |

## Запуск

1. Найдите все заглушки: `grep -rn "TODO\|000-00-00\|79000000000\|username\|example.ru\|Иванов" .`
   и замените имя, телефон, мессенджеры, адрес, реквизиты, цены, фото, отзывы.
2. `cp config.sample.php config.php` и укажите токен Telegram-бота и/или почту.
3. Создайте счётчик в [Яндекс Метрике](https://metrika.yandex.ru) и впишите номер в `assets/js/config.js` (`metrikaId`).
4. Залейте файлы на хостинг, подключите SSL (HTTPS обязателен для рекламы).
5. Замените `example.ru` в `robots.txt` и `sitemap.xml`, добавьте сайт в Яндекс Вебмастер.

Локальная проверка: `php -S 127.0.0.1:8080` и откройте http://127.0.0.1:8080.

## Цели Яндекс Метрики

Создайте в Метрике цели типа «JavaScript-событие» с идентификаторами:

| Цель | Когда срабатывает |
|---|---|
| `lead` | любая отправленная заявка (**главная цель для Директа**) |
| `lead_form` | заявка из формы / модального окна |
| `quiz_lead` | заявка из квиза |
| `quiz_start` | начали проходить квиз |
| `open_form` | открыли окно заявки |
| `click_phone` | клик по телефону |
| `click_whatsapp`, `click_telegram` | клик по мессенджеру |

Дополнительно можно сделать цель «Посещение страницы» `thanks.html`.
Составная цель «Все контакты» = `lead` + `click_phone` + `click_whatsapp` + `click_telegram` удобна для оптимизации конверсий в Директе.

## Яндекс Директ

**Ссылка в объявлении** (UTM-шаблон Директа):

```
https://ваш-сайт.ru/?s=bankrotstvo&utm_source=yandex&utm_medium=cpc&utm_campaign={campaign_id}&utm_content={ad_id}&utm_term={keyword}
```

- Параметр `s` подменяет заголовок первого экрана под объявление. Готовые ключи:
  `bankrotstvo`, `semya`, `nasledstvo`, `potrebitel`, `zastroyshik`, `dtp`.
  Добавить свой — в `assets/js/config.js` → `offers`.
- Все UTM-метки сохраняются на 30 дней и приходят вместе с заявкой в Telegram:
  видно, какая кампания и ключевая фраза принесли клиента.
- Рекомендуемая стратегия после набора статистики — «Максимум конверсий» с оплатой за конверсии по цели `lead`.
- Делайте отдельную группу объявлений под каждую услугу и ведите её на свой `?s=...`.

**Модерация юридических услуг в Директе:**
- на сайте должны быть реквизиты (ИП/самозанятый/ООО, ИНН, ОГРН/ОГРНИП) и реальные контакты — блок в подвале;
- нельзя писать «гарантируем победу», «100 % выигрыш», «лучший юрист» без подтверждения (ФЗ «О рекламе», ст. 5) — тексты сайта уже составлены с учётом этого;
- слово «адвокат» можно использовать, только если есть статус адвоката; иначе — «юрист»;
- цифры в блоке «Обо мне» должны быть правдивыми — замените заглушки на реальные данные.

## Авито Услуги

- В объявлениях Авито **нельзя размещать ссылки на сайт и контакты в тексте** — объявление заблокируют. Клиенты с Авито приходят через звонки и чат Авито.
- Сайт работает как подтверждение надёжности: отзывы с Авито можно показать в блоке «Отзывы» (скриншоты или цитаты со ссылкой на профиль).
- Если в профиле Авито есть поле «Сайт» (для бизнес-аккаунтов), укажите ссылку с меткой:
  `https://ваш-сайт.ru/?utm_source=avito&utm_medium=profile`.

## Другие площадки

Ставьте ссылку с меткой `utm_source=<площадка>`, чтобы видеть источник заявки:

- **Яндекс Бизнес / Яндекс Карты** — карточка организации, отзывы, кнопка «Сайт» (`utm_source=yandex_maps`);
- **2ГИС** (`utm_source=2gis`);
- **Профи.ру, ВКонтакте, Telegram-каналы** (`utm_source=profi`, `vk`, `telegram`).

## Юридические моменты сайта

- Чекбокс согласия на обработку ПД стоит в каждой форме; текст политики — `privacy.html` (проверьте и заполните реквизиты).
- Подайте уведомление об обработке ПД в Роскомнадзор (pd.rkn.gov.ru) — с сентября 2022 г. оно обязательно почти для всех операторов, в том числе собирающих заявки через сайт.
- Заявки уходят в Telegram — это передача данных за рубеж; если это критично, используйте только почту на российском сервисе или сохраняйте заявки в `leads.log` на российском хостинге.
